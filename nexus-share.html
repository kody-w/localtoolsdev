How to reuse this in your own app

The transport lives in window.NexusNet. Minimal usage: 

const net = new NexusNet({
  appId: 'my-app',
  meta: { name: 'Alice' },
  onReady:  (code, url) => showQR(url),
  onData:   (peerId, d) => handle(d),
  onPeerJoin: id => {}, onPeerLeave: id => {},
  onStatus: (state, msg, transport) => {}
});
net.host();            // or net.join('CODE')
net.broadcast({ ... }); // or net.send(peerId, {...})
